# Contributing

1. Read `AGENTS.md`, `SECURITY.md` and `TASKS.md`.
2. Use small pull requests against `develop`.
3. Add migrations for schema changes.
4. Include tests for authorization and anything that touches health records.
5. Run format, lint and tests (see `TASKS.md`).
6. Update documentation when behavior or architecture changes.
7. Do not commit secrets, dumps of health data, or production `.env` files.

Code of conduct: be precise, be kind, do not treat health topics as a joke in product copy.
